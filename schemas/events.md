# Schemas

The engine relies on a standardized set of structures to ensure data consistency between the remote queue and local analysis.

## Internal Event Schema

The Internal Event Schema represents the raw, foundational data structure ingested from the queue by the Collector.

```go
type RawEvent struct {
    ID                 string            `json:"id"`
    Body               string            `json:"body"`
    Provider           string            `json:"provider"`             // e.g., "SQS", "RabbitMQ"
    Attributes         map[string]string `json:"attributes"`
    FirstSeen          time.Time         `json:"first_seen"`
    LastSeen           time.Time         `json:"last_seen"`
    ReceiveCount       int               `json:"receive_count"`
    OriginalQueueName  string            `json:"original_queue_name"`
}
```

## Failure Record Schema

The Failure Record Schema extends the raw event with deterministic classifications generated by the Normalizer and Classifier.

```go
type FailureRecord struct {
    RawEventID      string `json:"raw_event_id"`
    ErrorSignature  string `json:"error_signature"`    // The SHA-256 hash of the normalized error
    NormalizedError string `json:"normalized_error"`
    PayloadShape    string `json:"payload_shape"`      // JSON key structure fingerprint (e.g., "error,payload.action,payload.id")
    FailureClass    string `json:"failure_class"`      // Group identifier from the Classifier
    Classification  string `json:"classification"`     // E.g., "Poison Message", "Downstream Dependency"
    Severity        string `json:"severity"`           // "critical", "warning", "info"
    RetryVerdict    string `json:"retry_verdict"`      // "safe_to_retry", "do_not_retry", "retry_with_backoff", "needs_investigation"
}
```

## Timeline Schema

The Timeline Schema represents the analytical aggregation of Failure Records, used by the Reporter to build high-level summaries for engineers.

```go
type Timeline struct {
    FailureClass      string    `json:"failure_class"`
    Severity          string    `json:"severity"`
    RetryVerdict      string    `json:"retry_verdict"`
    Count             int       `json:"count"`
    Percentage        float64   `json:"percentage"`          // percentage of total messages
    UniqueSignatures  int       `json:"unique_signatures"`   // distinct error hashes within this class
    FirstOccurrence   time.Time `json:"first_occurrence"`
    LastOccurrence    time.Time `json:"last_occurrence"`
    Duration          string    `json:"duration"`            // human-readable window length
    RetryPattern      string    `json:"retry_pattern"`       // "Instant Death", "Exhaustion", "Mixed"
    AvgReceiveCount   float64   `json:"avg_receive_count"`
    MaxReceiveCount   int       `json:"max_receive_count"`
    PeakHourlySpike   int       `json:"peak_hourly_spike"`
    RecommendedAction string    `json:"recommended_action"`
    SamplePayload     string    `json:"sample_payload"`
    SampleError       string    `json:"sample_error"`        // normalized error for reference
    PayloadShapes     []string  `json:"payload_shapes"`      // distinct payload key structures in this class
    BurstAnalysis     string    `json:"burst_analysis"`      // human-readable burst assessment
}
```

## Triage Group Schema

Groups failure classes by action urgency for the executive summary.

```go
type TriageGroup struct {
    Label    string     `json:"label"`           // "Immediate Action Required", "Safe to Retry", "Needs Investigation"
    Classes  []Timeline `json:"classes"`
    Messages int        `json:"total_messages"`
}
```

## Report Summary Schema

The top-level output produced by the Analyzer and consumed by the Reporter.

```go
type ReportSummary struct {
    RunName          string        `json:"run_name"`
    TotalMessages    int           `json:"total_messages"`
    TotalClasses     int           `json:"total_classes"`
    CriticalCount    int           `json:"critical_count"`
    SafeToRetryCount int           `json:"safe_to_retry_count"`
    SafeToRetryMsgs  int           `json:"safe_to_retry_messages"`
    DoNotRetryCount  int           `json:"do_not_retry_count"`
    DoNotRetryMsgs   int           `json:"do_not_retry_messages"`
    WindowStart      time.Time     `json:"window_start"`
    WindowEnd        time.Time     `json:"window_end"`
    WindowDuration   string        `json:"window_duration"`
    ExecutiveSummary string        `json:"executive_summary"`
    Triage           []TriageGroup `json:"triage"`
    Timelines        []Timeline    `json:"classes"`
}
```

## RunSummary Schema

Represents an aggregated overview of a previously imported DLQ inspection run.

```go
type RunSummary struct {
    Name         string    `json:"name"`
    MessageCount int       `json:"message_count"`
    FirstSeen    time.Time `json:"first_seen"`
    LastSeen     time.Time `json:"last_seen"`
}
```

## Detail Record Schema

Joined view of a failure record + raw event, used by the `detail` command to show individual messages.

```go
type DetailRecord struct {
    MessageID       string
    Body            string
    ReceiveCount    int
    FirstSeen       time.Time
    LastSeen        time.Time
    ErrorSignature  string
    NormalizedError string
    PayloadShape    string
    FailureClass    string
    Classification  string
    Severity        string
    RetryVerdict    string
}
```

## Diff Class Summary Schema

Per-class counts used by the `diff` command to compare two runs.

```go
type DiffClassSummary struct {
    FailureClass   string
    Classification string
    Severity       string
    RetryVerdict   string
    Count          int
}
```
